# FinderFavorites

FinderFavorites 是一款专为 macOS 用户打造的 Finder 增强工具，让您的文件管理效率提升 10 倍！

### ✨ 核心功能

1. **快速收藏** ⭐
    - 一键收藏当前 Finder 路径
    - 最多支持收藏 7 个常用文件夹（免费版限制）
    - 双击 Finder 空白区域快速访问收藏夹

2. **智能导航** 📁
    - 支持子菜单展开，无需打开新窗口
    - 点击即可快速跳转到目标文件夹
    - 自动记忆最近打开的文件和文件夹

3. **多显示器支持** 🖥️
    - 完美适配多显示器环境
    - 菜单自动显示在鼠标所在显示器
    - 精准的坐标转换算法

4. **系统级集成** 🔧
    - 与 macOS 深度集成，原生体验
    - 状态栏快速访问，不占用 Dock 空间
    - 支持 Alfred 等效率工具联动

### 📦 免费版限制

- 最多收藏 7 个文件夹
- 部分高级功能需要升级到专业版

### 📝 使用说明

1. 下载并安装 DMG 文件
2. 打开 FinderFavorites.app
3. 在状态栏点击 FinderFavorites 图标开始使用
4. 点击「⭐ 收藏当前 Finder 路径」添加常用文件夹
5. 双击 Finder 空白区域快速访问收藏夹
